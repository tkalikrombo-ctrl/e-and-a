# E&A: English for MIS

تطبيق عربي بواجهة RTL لتعلّم الإنجليزية عبر مواقف ومشروعات من نظم المعلومات الإدارية، مع قاموس ترجمة إنجليزي–عربي ونطق للكلمات والأمثلة. التمارين التقنية باللغة الإنجليزية، والتقدّم محفوظ محلياً على الجهاز.

## التشغيل والتحقق

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Android APK

يتطلب البناء JDK 21 وAndroid SDK Platform 36 وBuild Tools 36.0.0، مع قبول تراخيص Android SDK. بعد إعداد `JAVA_HOME` و`ANDROID_HOME`:

```powershell
npm run android:apk
```

ينتج ملف Debug APK في `android/app/build/outputs/apk/debug/app-debug.apk`. هذه نسخة للاختبار وليست مخصصة للنشر على Google Play.

يمكن بناء التطبيقين من GitHub Actions عبر **Build Android and Windows apps**. وعند إنشاء Tag ودفعه، ينشر Workflow الإصدار في GitHub Releases. تستخدم إصدارات Actions الحالية مفتاح Debug مؤقتاً؛ النشر العام وتحديثات التطبيق السلسة تتطلب مفتاح Release ثابتاً محفوظاً في GitHub Secrets.

## Windows

ينشئ GitHub Actions تطبيق Windows محمولاً بصيغة `.exe` وينشره مع APK في صفحة GitHub Releases نفسها. حمّل `EA-Windows.exe` وشغّله مباشرة؛ لا يحتاج إلى تثبيت. التطبيق غير موقّع رقمياً، لذلك قد يعرض Windows تحذير SmartScreen؛ التوزيع التجاري يحتاج شهادة توقيع تطبيقات.

## الميزات

- مسارات في إدارة قواعد البيانات، وتحليل النظم، وإدارة مشاريع تقنية المعلومات، والتجارة الإلكترونية؛ من مستوى A1 إلى C1.
- تحديات كتابة وتحدث، وتسجيل صوتي محلي قابل للمعاينة والتنزيل.
- مواعيد أسبوعية وتذكيرات محلية على Android، وتنبيهات متصفح عند دعمها.
- تسجيل جلسات التعلّم محلياً، مع تقدّم منفصل لكل درس وسجل نشاط أسبوعي.
- نقاط خبرة تُمنح عند إكمال كل درس لأول مرة، مع سلسلة تعلّم وإحصاءات مشتقة من الجلسات.
- قاموس تخصصي قابل للبحث بالإنجليزية أو العربية، مع أمثلة ومفضّلة يعمل دون إنترنت.
- اختيار صوت النطق وسرعته من الأصوات المثبتة على الجهاز. من تبويب **القاموس** افتح تنزيل Google Speech Services على Android، أو إعدادات الكلام على Windows لإضافة أصوات؛ ثم اضغط **تحديث الأصوات**. الأصوات يديرها نظام الجهاز وقد يحتاج بعضها إلى إنترنت.
- واجهة متجاوبة للهاتف وسطح المكتب، ودعم كامل لاتجاه العربية RTL.
